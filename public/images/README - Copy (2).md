# Foto SMKN 4 Bogor untuk Homepage

## Cara Menggunakan Foto Asli SMKN 4 Bogor

### 1. Siapkan 3 Foto Utama:
- **`smkn4bogor-lapangan.jpg`** - Foto lapangan basket biru-kuning dengan logo "SMK NEGERI 4 BOGOR HEBAT"
- **`smkn4bogor-upacara.jpg`** - Foto upacara bendera dengan siswa berbaris rapi
- **`smkn4bogor-gedung.jpg`** - Foto gedung sekolah dengan atap genteng merah

### 2. Simpan Foto di Folder Ini:
- Pastikan nama file sama persis dengan yang disebutkan di atas
- Format: JPG/JPEG
- Resolusi: Minimal 1920x1080 (Full HD)
- Ukuran file: Optimal di bawah 2MB

### 3. Setelah Foto Disimpan:
- Refresh halaman homepage
- Carousel akan otomatis menggunakan foto asli SMKN 4 Bogor
- Background akan berganti sesuai foto yang dipilih

### 4. Deskripsi Foto:
- **Slide 1**: VISI SEKOLAH - Gunakan foto lapangan basket
- **Slide 2**: TEKNOLOGI & INOVASI - Gunakan foto upacara bendera  
- **Slide 3**: PRESTASI & KEBERHASILAN - Gunakan foto gedung sekolah

### 5. Jika Foto Belum Muncul:
- Periksa nama file (harus sama persis)
- Pastikan format file adalah JPG/JPEG
- Cek apakah file tersimpan di folder yang benar
- Refresh halaman dengan Ctrl+F5 (hard refresh)
